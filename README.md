# PSC Content Repository (CDN Distribution for State PSC App Engine)

This repository serves real-time exam questions, syllabus updates, and mock tests to all mobile apps powered by the **PSC App Engine** via **jsDelivr CDN**.

## ⚡ How it Works with Flutter Mobile Apps

Every app generated by the engine checks this repository via jsDelivr CDN:
```text
https://cdn.jsdelivr.net/gh/<YOUR_GITHUB_USERNAME>/psc-content@main/exams/<EXAM_ID>/config.json
```

### 3-Tier Dynamic Fallback:
1. **Memory Cache:** Instant in-memory rendering.
2. **Local Disk Cache:** Downloaded updates saved locally on user's device (`getApplicationDocumentsDirectory()`).
3. **Bundled Asset Seed:** Day-1 offline data bundled inside APK/AAB — the app works seamlessly even without an internet connection on first launch.

## 🚀 How to Publish on GitHub

1. Create a **public** repository on GitHub named `psc-content`.
2. Push this folder to GitHub:
   ```bash
   cd psc-content
   git init
   git add .
   git commit -m "Initial commit of exam content"
   git branch -M main
   git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/psc-content.git
   git push -u origin main
   ```
3. Update `cdnRepo` in your app configs (`bpsc_config.dart`, `mpsc_config.dart`, etc.) or in Studio with your GitHub username:
   ```dart
   cdnRepo: '<YOUR_GITHUB_USERNAME>/psc-content'
   ```
